# FocusLock

一个原生 macOS 番茄钟，专注期间可以锁定指定的 App。SwiftUI + Swift Charts，无第三方依赖。

## 功能

- **番茄钟**：倒计时（15/25/45/60 分钟预设或自定义 1–240 分钟）/ 正计时；开始、暂停、继续、结束（保存）、放弃（不保存）；空格键开始/暂停
- **锁定应用**：专注时，已经打开的锁定 App 会被要求退出；新打开的会被立即关闭，并弹回 FocusLock、发系统通知
  - 暂停时可选保持锁定
  - 严格模式：倒计时结束前不能暂停、结束、放弃或退出，也不能改锁定设置
- **分类**：自定义名称和颜色，可拖动排序
- **统计**：今天 / 近 7 天 / 近 30 天 / 全部；分类占比环形饼图 + 按小时/天/月堆叠柱状图；总时长、次数、完成番茄数、日均
- **记录**：按天分组，可按分类筛选、删除
- **菜单栏**：实时显示剩余时间，可直接暂停/继续；关掉窗口后照样计时和锁定
- 合盖睡眠时自动暂停；不足 1 分钟的专注不记录

## 构建

只需要 Xcode Command Line Tools（`xcode-select --install`），不需要完整 Xcode：

```bash
./build.sh            # 生成 build/FocusLock.app
./build.sh install    # 并复制到 /Applications
```

第一次构建会编译系统模块缓存，大约需要 1–2 分钟。

## 数据

保存在 `~/Library/Application Support/FocusLock/data.json`。设置环境变量 `FOCUSLOCK_DATA_DIR` 可以改用其他目录（测试用）。

## 局限

- 锁定只在 FocusLock 运行时生效。强制退出 FocusLock（活动监视器）就能解除，自己给自己上锁本来就防不住管理员。
- 只能按 App 锁定，不能屏蔽网站。
